# Project assets

The team supplied starter files `hero.png`, `react.svg` and `vite.svg` are preserved in this folder. The original `public/icons.svg` is also retained. The Home page no longer imports these starter assets.

Current page photographs, the supplied Luminary logo and the public domain map are in `public/images`. Photography source records are in `src/image-data.js`, `src/portrait-data.js`, the page's Image credits and `public/images/portraits`.

Local fonts and social marks have source and licence records in `public/fonts` and `public/social`. The star favicon at `public/favicon.svg` is a decorative asset for the Home page. The connected world star is an optical light effect in `src/WorldArtwork.jsx`; no generated photographic faces or community scenes are displayed.
